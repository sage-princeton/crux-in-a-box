1. **Presentation overhaul, for a cold reader.** Restructure, don't sand: one clear contribution statement up front; abstract rewritten to 5–6 sentences within the word cap; cut hedges that repeat — a limitation is stated once, precisely, in the Limitations section; every table/figure interpretable from its caption alone; kill author-internal vocabulary. 2. **Figures.** At least one real main-body figure that carries the headline result. Build from cached artifacts — no new experiments in this window.
3. **Hard caps, gate-checked.** `REQUIRE_PRESENTATION=1 REQUIRE_README=1 REQUIRE_EXTERNAL_REVIEWS=1 ./scripts/gate_artifact.sh paper/paper.pdf paper` must pass: main-body page budget, abstract cap, figure present, no ALL-CAPS prose, external review on file.

5. **The final README.** Rewrite `README.md` for a stranger who has never seen this run: what was asked, what was found (one paragraph, plain language), where the paper is, a repo map, and an exact reproduction path for the headline result from a fresh clone. Commit it last.
6. **Harvest, don't launch.** Fold in results from still-running jobs if they land; start nothing new that couldn't finish well inside this window.
