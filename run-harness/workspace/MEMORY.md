## Lessons Learned

_Append a lesson only when you catch yourself (or a subagent) actually failing. Each lesson is a checkable rule, not a story. This section is the highest-value text in the workspace precisely because it is earned — do not pad it._

- **(seed) Prose-as-fact is the default failure mode under pressure.** It has one shape: quoting a summary without ever deriving it from the artifact. Typical instances: a headline number that reproduces from no artifact; an N-of-M claim generalized from a partial audit; a fluent summary of a file never actually opened. **Rule (binding via AGENTS.md evidence heuristic #1, *artifact-or-it-didn't-happen*):** a load-bearing statistic gets a committed re-derivation script **once — when it is first promoted to a claim** (its first prose appearance), not re-run every round; any "summarize X" reads X first; a subagent number reaches prose only after a spot-check when it is surprising or claim-bearing (AGENTS.md *spot-check, don't re-audit*).
