CRUX on AWS — resources provisioned by src/

Two EC2 roles in the default VPC: a persistent control box (AgentRQ dashboard, workspaces, task queue) and N ephemeral run boxes (codex + ACP gateway) that dial it on :443. Caddy fronts AgentRQ with a real Let's Encrypt certificate for <dashed-eip>.sslip.io, so the dashboard is plain HTTPS from the operator's /32, and is the only access path — :22 and :443 share that gate, so a changed address is fixed by reopening the security group, not by falling back to SSH. Control-plane access is granted by an SG-to-SG reference, not a CIDR.

Three constraints force the run-box path shown below, and only that combination satisfies them: Host must equal AGENTRQ_DOMAIN or AgentRQ returns a flat 404; the certificate is issued for the public name, so TLS must be spoken to it; and an SG reference matches only traffic arriving on a private address — dialling the Elastic IP from inside the VPC arrives with the run box's public source address and times out. Hence :443 to the public hostname, pinned to the control box's private IP in /etc/hosts.
