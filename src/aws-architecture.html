CRUX on AWS — resources provisioned by src/

Two EC2 roles in the default VPC: a persistent control box (AgentRQ dashboard, workspaces, task queue) and N ephemeral run boxes (codex + ACP gateway) that dial it on :2026. No public web port anywhere — the dashboard is reached over SSH (connect.sh port-forward or SOCKS). Control-plane access is granted by an SG-to-SG reference, not a CIDR.
