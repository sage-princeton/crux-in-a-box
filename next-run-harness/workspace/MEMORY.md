## Lessons Learned

_Append a lesson only when you catch yourself (or a subagent) actually failing. Each lesson is a checkable rule, not a story. This section is the highest-value text in the workspace precisely because it is earned — do not pad it._

- **(seed) Prose-as-fact is the default failure mode under pressure.** It has one shape: quoting a summary without re-deriving it from the artifact in the same session. Typical instances: a headline number that reproduces from no artifact; an N-of-M claim generalized from a partial audit; a fluent summary of a file never actually opened. **Rule (binding via AGENTS.md evidence rules):** every load-bearing statistic gets a committed re-derivation script and a `REGISTRY.md` row at first prose appearance; any "summarize X" reads X first; subagent numbers never go into prose directly.
