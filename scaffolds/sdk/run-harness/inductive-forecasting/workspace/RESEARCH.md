# Research question

When language models make judgmental forecasts, do they reason inductively?

# Context

Judgmental forecasting involves predicting uncertain events like elections or
geopolitical conflicts where abundant historical data is lacking. A key challenge
is induction: forecasters must generalize from sparse evidence and contextual
knowledge to infer how available evidence predicts future outcomes. The goal is to
understand whether language models (LMs) recover and use such predictive
relationships when forecasting, rather than relying on base rates or surface cues.
The agent should (a) define a set of criteria for capability in inductive
forecasting, grounded in the broad cognitive science literature on this topic, (b)
design and implement a set of experiments to test these criteria against plausible
alternative explanations, and (c) build at least one causal design that sheds light
on the mechanisms behind this capability.
